# Quantum Admin

The administration interface for Quantum projects, run with `quantum admin`
(`pip install "quantum-framework[admin]"`). How to use it:
[docs/guide/admin.md](../docs/guide/admin.md).

## Layout

```
quantum_admin/
├── components/admin/   # the screens, written in Quantum (.q)
├── assets/             # their CSS and JavaScript
├── services/           # what the screens call (q:invoke service=...)
├── core/               # the library the services use: models, database,
│                       # CRUD, auth, connectors, settings, secrets
├── backend/            # the old FastAPI admin — in the repository only
├── settings/           # the owner's settings (never touched by tests)
└── INVENTORY.md        # generated by scripts/admin-inventory.py
```

`components`, `assets`, `services` and `core` are what the wheel ships.

## The old FastAPI backend

`backend/` is the admin as it was before the screens moved to `.q`
(`main.py`, ~270 routes). It is not in the wheel; it stays while its areas are
rewritten and is still covered by `tests/admin/test_admin_smoke.py`. The
modules it shared with the new admin now live in `core/`; `backend/` keeps
shims under their old names.

To run it from a checkout:

```bash
pip install -r quantum_admin/backend/requirements.txt
ADMIN_PASSWORD="a long password" JWT_SECRET_KEY="..." python quantum_admin/backend/run.py
```

There are no default credentials: without `ADMIN_PASSWORD` the password and the
token key are random for each run.
