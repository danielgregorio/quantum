# Examples

The examples live in two places, and all of them are run by Quantum's test
suite:

- The [Cookbook](../cookbook/index.md): short recipes for one task each. Every
  recipe is a small app with tests, and its page shows the tested files.
- The [Showcase](../showcase/index.md): the complete apps in the repository,
  with what each one demonstrates and a screenshot of it running.

To build a whole app step by step, follow the [tutorial](../tutorial/tasks-app.md).
