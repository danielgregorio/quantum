## [Construye la aplicación de tareas](./tasks-app.md)

De `pip install` a una aplicación completa: una lista de tareas con
formularios validados, botones para terminar y eliminar, un filtro, una tabla
que se ordena y se edita sola, una página de edición con el historial de cada
cambio, y un conjunto de pruebas con `quantum test`. Ocho pasos, sin
JavaScript.

El conjunto de pruebas de Quantum ejecuta el código de cada paso tal como se
muestra, y la aplicación terminada es la de
[`projects/tarefas`](https://github.com/danielgregorio/quantum/tree/main/projects/tarefas).

¿Eres nuevo en Quantum? El [Inicio rápido](../guide/quick-start.md) toma cinco
minutos.
