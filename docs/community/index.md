# Community

Quantum is developed in the open on
[GitHub](https://github.com/danielgregorio/quantum).

## Questions, bugs and ideas

Open an [issue](https://github.com/danielgregorio/quantum/issues/new/choose).
For a bug, a **minimal `.q` file that reproduces it** — and what you expected
instead — is the fastest way to a fix.

## Contributing

[CONTRIBUTING.md](https://github.com/danielgregorio/quantum/blob/main/CONTRIBUTING.md)
takes you from a fresh clone to a merged pull request: the development setup,
how a tag is a parser plus an executor, and how the tests are organised. A
change in behaviour comes with a rule in
[SPEC.md](https://github.com/danielgregorio/quantum/blob/main/SPEC.md) and a
test that cites it.

## Code of conduct

Everyone taking part agrees to the
[Code of Conduct](https://github.com/danielgregorio/quantum/blob/main/CODE_OF_CONDUCT.md).

## Security

Please **do not** report a vulnerability in a public issue. The
[security policy](https://github.com/danielgregorio/quantum/blob/main/SECURITY.md)
says how to report one privately, and which versions receive fixes.

## Keeping up

The [blog](../blog/index.md) has release news (with an RSS feed), and the
[changelog](../changelog/index.md) lists every change, version by version.
