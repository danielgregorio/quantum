O Quantum é desenvolvido abertamente no
[GitHub](https://github.com/danielgregorio/quantum).

## Perguntas, bugs e ideias {#questions-bugs-and-ideas}

Abra uma [issue](https://github.com/danielgregorio/quantum/issues/new/choose).
Para um bug, um **arquivo `.q` mínimo que o reproduza** — e o que você
esperava no lugar — é o caminho mais rápido para uma correção.

## Contribuir {#contributing}

O [CONTRIBUTING.md](https://github.com/danielgregorio/quantum/blob/main/CONTRIBUTING.md)
leva você de um clone novo até um pull request aceito: o ambiente de
desenvolvimento, como uma tag é um parser mais um executor, e como os testes
estão organizados. Uma mudança de comportamento vem com uma regra no
[SPEC.md](https://github.com/danielgregorio/quantum/blob/main/SPEC.md) e um
teste que a cita.

## Código de conduta {#code-of-conduct}

Todos que participam concordam com o
[Código de conduta](https://github.com/danielgregorio/quantum/blob/main/CODE_OF_CONDUCT.md).

## Segurança {#security}

Por favor, **não** relate uma vulnerabilidade numa issue pública. A
[política de segurança](https://github.com/danielgregorio/quantum/blob/main/SECURITY.md)
diz como relatá-la em particular, e quais versões recebem correções.

## Acompanhar {#keeping-up}

O [blog](/pt/blog/) tem as notícias das versões (com um feed RSS), e o
[registro de mudanças](/changelog/) (em inglês) lista cada mudança, versão por
versão.
