## [Construa a aplicação de tarefas](./tasks-app.md)

Do `pip install` a uma aplicação completa: uma lista de tarefas com
formulários validados, botões para concluir e apagar, um filtro, uma tabela
que se ordena e se edita no lugar, uma página de edição com o histórico de
cada mudança, e uma suíte de testes `quantum test`. Oito passos, nenhum
JavaScript.

O código de cada passo é executado pela própria suíte de testes do Quantum
exatamente como aparece, e a aplicação pronta é a de
[`projects/tarefas`](https://github.com/danielgregorio/quantum/tree/main/projects/tarefas).

Nunca usou Quantum? O [Início rápido](../guide/quick-start.md) leva cinco
minutos.
