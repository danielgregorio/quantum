Quantum 今天是什么，接下来做什么。这里没有日期，也不作[支持层级](https://github.com/danielgregorio/quantum/blob/main/SUPPORT_TIERS.md)之外的承诺：
一个事项只有在某个版本中发布、并且[更新日志](/changelog/)中写明之后，才算完成。

每个事项都标明状态：**计划中**（已批准，尚未开始）、**设计中**（在写任何代码之前先写下设计）或**进行中**（正在构建）。

## 1.0——今天

Quantum 1.0 是用 XML 编写的声明式 Web 应用，语言内置 AI 与 RAG。1.0 的承诺由它的层级确定：

- **核心层（Core）**（组件、查询与事务、动作与表单、文件、邮件、认证、`ui:*` 的核心集合）和
  **AI 层**（`q:llm`、`q:knowledge`、`q:agent`）遵循语义化版本：1.x 版本不会破坏只使用这两层的程序。
  AI 层还会在每次发布前针对真实模型进行测试。
- **实验层（Experimental）** 的标签可以工作，但没有稳定性承诺。
- **实验室（Laboratory）** 的项目留在仓库中，因为它们在推动语言向前；它们不属于产品，也没有任何承诺。

今天能运行的内容是测量出来的，而不是宣称的：见[状态](/status/)。每个标签和每条规则都在[参考](/reference/)中。
