Quantum 在 [GitHub](https://github.com/danielgregorio/quantum) 上公开开发。

## 问题、bug 与想法 {#questions-bugs-and-ideas}
提交一个 [Issue](https://github.com/danielgregorio/quantum/issues/new/choose)。
报告 bug 时，一个**能复现它的最小 `.q` 文件**——以及你原本期望的结果——是最快得到修复的方式。

## 参与贡献 {#contributing}
[CONTRIBUTING.md](https://github.com/danielgregorio/quantum/blob/main/CONTRIBUTING.md)
带你从一个新的克隆走到被合并的 Pull Request：开发环境、一个标签如何由解析器加执行器构成，以及测试是如何组织的。
行为上的改变要附带 [SPEC.md](https://github.com/danielgregorio/quantum/blob/main/SPEC.md) 中的一条规则，以及引用该规则的测试。

## 行为准则 {#code-of-conduct}
所有参与者都同意遵守[行为准则](https://github.com/danielgregorio/quantum/blob/main/CODE_OF_CONDUCT.md)。

## 安全 {#security}
请**不要**在公开的 Issue 中报告漏洞。
[安全策略](https://github.com/danielgregorio/quantum/blob/main/SECURITY.md)说明了如何私下报告，以及哪些版本会得到修复。

## 保持关注 {#keeping-up}
[博客](/blog/)发布版本新闻（带有 RSS 订阅），[更新日志](/changelog/)按版本列出每一处变更。
