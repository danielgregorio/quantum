# Support Quantum

Quantum is free and open source (MIT), and it will stay that way. It is
maintained by one person, in their own time. Support pays for what keeps it
honest and available:

- **The domain and the demo server** — the site, and a place where the
  examples run live.
- **The machine that runs the AI tests and the benchmarks** — the AI tags are
  tested against a real model before every release, and that needs a machine
  with enough memory to run one.
- **Maintenance time** — reviewing issues and pull requests, keeping the
  specification and its conformance tests in step with the code, and releases.

## How to help

- **Use it and tell us what broke.** A minimal `.q` file that reproduces a bug,
  in a [GitHub issue](https://github.com/danielgregorio/quantum/issues), is worth
  more than any amount of praise.
- **Contribute** — see [Community](../community/index.md).
- **Sponsor** — not open yet.
