# Arquivo — documentação histórica

Os documentos nesta pasta descrevem o estado do projeto **em algum momento passado**.
Foram movidos para cá em 2026-09-07 (ver `DOCS_CONSOLIDATION_PLAN.md` na raiz do repo)
porque uma auditoria funcional (`FULL_AUDIT_2026-09.md`) confirmou que vários deles
contradiziam a realidade do código — não porque o conteúdo não teve valor no seu tempo.

**Nenhum arquivo aqui deve ser tratado como fonte de verdade sobre o estado atual do
projeto.** Para status atual, veja `FEATURE_STATUS.md` na raiz (gerado por verificação
real, não editado à mão) e `CLAUDE.md`.

Estrutura preservada das pastas originais (`quantum-as4/`, `quantum_admin/`,
`docs-proposals/`) para manter o contexto de onde cada doc vivia.
